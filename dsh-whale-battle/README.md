## 这是什么

DSH 插件市场里桌宠有几十个，但基本都是**状态气泡**：显示余额、播报进度、跟着 agent 换表情。
这个插件想做另一件事——**把桌宠做成一个真的能玩的小游戏**，而且战斗不是纯文字日志：

- 一条会摇尾巴、会喷水、会眨眼的小鲸鱼，拖得动、点得开；
- 点开是一整块面板：**对战 / 养成 / 队伍 / 说明**；
- 十二关主线，回合制自动战斗：属性克制、暴击、持续伤害、冰冻眩晕、怒气绝招、3v3 轮战；
- **战斗动作**：出手前冲、受击抖动、命中冲击波、伤害/治疗飘字、技能名横幅、倒地变灰；
- 升级学新技能、进化形态（幼鲸 → 小鲸鱼 → 鲸鱼少年 → 冰原鲸 → 鲸王）；
- 战斗在**宿主**结算，前端只负责按帧回放——跳过动画、刷新页面都不改变结果。

灵感来自 QQ 宠物 / Q宠大乐斗那一挂。**形象与美术是原创的**，和腾讯没有任何关系，玩法致敬。
0.2.0 起角色从企鹅换成了鲸鱼，旧存档会自动迁移。

## 🖥 桌面宠物（Windows，0.3.0 新增）

页面里的鲸鱼可以**离开浏览器**：一个真正置顶、透明、无边框的独立小窗，浮在所有窗口上面
（全屏游戏也盖得住，独占全屏除外），可以拖到屏幕任意位置。

- **透明分层窗口**：逐像素 alpha，鲸鱼和气泡之外的地方完全透明，不挡别的窗口
- **会动**：上下浮动、随机眨眼、心情好时偶尔眯眼笑
- **右键菜单**：喂食 / 洗澡 / 陪玩 / 训练 / 睡觉 / 打工 / 隐藏 30 分钟 / 退出
- **点一下鲸鱼**：展开状态卡（饱食 / 清洁 / 心情 / 体力 + 金币）
- **气泡**：饿了、脏了、困了会主动说话；操作完把结果说出来
- **托盘图标**：关掉窗口后可以从托盘找回
- 拖到哪记到哪；DSH 关掉后它连不上接口，几次失败会自己退出

**不用装任何运行时**：第一次启动用 Windows 自带的 .NET Framework `csc.exe` 编译一次（约 1 秒），
产物和日志在 `%LOCALAPPDATA%\dsh-whale-battle\`。

两种启动方式：

1. **双击 `启动桌面鲸鱼.cmd`** —— 不依赖 DSH 界面，现在就能用（端口会从插件写下的
   `base-url.txt` 里读，读不到回退 `127.0.0.1:49236`）
2. **面板顶部的 🖥 按钮 / 说明页的「打开桌面宠物」** —— 由插件宿主编译并拉起，
   和游戏数据完全联动（需要宿主重载一次新代码后生效）

> 注意：桌面小窗只支持 Windows；macOS/Linux 仍然只有页面内悬浮。

## 它跟别的桌宠不一样的地方

> 鲸鱼吃的是你真实的活儿。

宿主会读 DSH 自己的会话日志（`$DSH_HOME/sessions/**/session*.jsonl.zstd`），只数四类事件的**条数**：

| 统计项 | 来源事件 |
| --- | --- |
| 完成步数 | `assistant/message` |
| 工具调用 | `tool/call` |
| 失败次数 | `tool/result` 里 `isError: true` |
| 回合数 | `turn/start` |

然后：

- **战斗经验加成** = `(工具调用 + 步数×2 + 回合×2) / 600`，封顶 +50%；
- **打工收益** = 基础金币 + `min(90, 工具调用/3)`，今天越忙，鲸鱼打工越值钱。

它**不读对话正文**（只数条数，正文长度只用于「字数」这一项兜底，不落盘、不外传）。
不想要这个联动，把 `lib/worklog.js` 的调用去掉就行，游戏本身照常跑。

## 快速开始

### 方式 A：从本地安装（推荐，先自己玩）

1. DSH → **设置 → 插件管理 → 从本地安装**，选中这个目录（里面要**直接**有 `package.json`）。
2. **刷新页面**（`Ctrl+F5`）——客户端插件要重新加载才生效。
3. 右下角出现鲸鱼，点它开面板。
4. 自检：把端口换成你自己的 DSH 端口

```bash
curl http://127.0.0.1:49236/dsh-whale-battle/state
```

返回 `{"ok":true,...}` 就说明宿主半边起来了。

### 方式 B：让 DSH 自己装

```
安装本地插件包 C:\path\to\dsh-whale-battle
```

### 方式 C：从 GitHub 装（发布之后）

```bash
dsh plugin --profile web add github:<你的用户名>/dsh-whale-battle
```

## 玩法

### 战斗

- **回合制自动战斗**：按速度排序出手，速度带 ±12% 抖动，同样的阵容也会打出不同过程。
- **属性相克**：冰克水、水克火、火克冰，克制伤害 ×1.5、被克 ×0.75。
- **怒气**：每回合 +28，攒到 100 放绝招；技能有 0 / 20~40 / 100 三档消耗。
- **伤害公式**：`攻击 × 技能倍率 × 减伤(防御) × 克制 × 随机(0.9~1.1) × 暴击1.6`，减伤项 `1 - def/(def+200)`。
- **异常状态**：燃烧/中毒（持续伤害）、冰冻/眩晕（跳回合）、破防（受伤 +25%）、攻击提升、护盾。
- **最多 3v3**：队伍里活着的鲸鱼轮流上场，倒下就退出本场。
- **40 回合上限**：打不完按双方剩余血量百分比判。

### 战斗动作（0.2.0 新增）

日志的每一帧都会翻译成一个「动作」，UI 按动作给单位和战场加状态：

| 日志 | 屏幕上的表现 |
| --- | --- |
| `hit` | 出手方朝对手方向前冲 12px；目标抖动 + 冲击波 + `-伤害` 飘字；暴击时飘字变大变红 |
| `heal` | 目标绿色描边发光，`+治疗` 飘字 |
| `shield` | 目标蓝色护盾徽标，`🛡+数值` 飘字 |
| `status` | 技能名横幅（按元素染色）+ 状态名 |
| `dot` | 目标抖动 + 持续伤害飘字 |
| `down` | 单位变灰、旋转倒下 |
| `end` | 结算浮层：胜负 / MVP / 金币经验 / 升级 |

技能横幅的颜色来自元素（冰蓝、水蓝、火橙、萌黄），配合 `--c` CSS 变量全局染色；速度 1×/2×/3× 随时可切，也可以直接「跳过」。

## 和 agent 一起玩

插件注册了三个工具，可以直接在对话里使唤它：

```
你：帮我看看鲸鱼现在怎么样
→ whale_status

你：喂它一口，然后替我把第二关打了
→ whale_care { action: "feed" }
→ whale_battle { stageId: 2 }
```

工具返回 JSON，包含金币、状态、等级、战斗摘要和奖励，模型能直接读。

## 数据与隐私

- 存档：`$DSH_HOME/dsh-whale-battle/save.json`（默认 `~/.dsh/dsh-whale-battle/save.json`），原子写，坏了自动重建。
- 0.2.0 首次启动会尝试从旧的 `dsh-penguin-battle/save.json` 迁移一次（名字也换成鲸鱼）。
- 会话统计：只读 `sessions/**/session*.jsonl.zstd` 的事件**条数**，带 mtime 缓存，最多扫 60 个文件、单文件 24MB 上限。
- 不联网、不上传、不要 API Key、零运行时依赖。
- 卸载插件不会删存档；要清干净就删 `~/.dsh/dsh-whale-battle/`。

> 为什么不打包？DSH 的浏览器半区只接受一个自包含的 `client.js`（模块工厂），
> 不允许 ESM import，也不该为了一个插件往用户机器上拖 `node_modules`。

### 怎么挂进界面的

客户端半区只做一件事：

```js
ctx.slots.inject('shell.overlay', () =>
  ctx.slots.register({ name: 'shell.overlay', id: 'whale-battle', order: 120 }, Overlay))
```

`shell.overlay` 是 DSH 布局插件在 root 作用域声明的 list 槽位，覆盖整个三栏框架；
我们的根节点 `pointer-events: none`，只有鲸鱼和面板自己收事件，所以不会挡住输入框。

### 动画是怎么做的

不引动画库，全部靠 CSS `@keyframes` + 每帧重新挂载精灵层：

1. 日志里每条带 `skillEl`（元素）和 `actor/target`（谁打谁）；
2. `actionOf(entry)` 把它翻译成 `{ type, actor, target, damage, color... }`；
3. `UnitCard` 根据「我是不是出手方/目标」决定加 `wb-anim-lunge-up` / `wb-anim-lunge-down` / `wb-anim-hit`；
4. 这几个 class 在 `.wb-unit-anim` 上，key 里带帧号——同一单位连续挨打也能重新抖动；
5. 冲击波、伤害数字用 `--c` 变量取元素色，浮在单位卡内部，不占布局。

## 已知限制

- 单机存档，没有云同步、没有联机对战。
- 战斗动画是「日志按帧回放」+ CSS 变换，没有骨骼/逐帧立绘；立绘是 SVG 现画的。
- 只统计本机会话日志，换机器就要重新开始（存档可以手动拷）。
- 目前只有中文界面。
